# 001 — Montazhka (демо-ролик)

- **Формат:** `16:9` (1920×1080, 30 fps)
- **Хронометраж:** ~30 секунд

## Сцены
1. **Заставка (Hero + 3D-камера):** Montazhka — локальный AI-контент-завод. Любой агент разворачивает его за одно сообщение и превращает текст в видео.
2. **Конвейер (4 шага):** Сценарий → Озвучка с пословными таймингами → Анимация на Remotion (в карточке: моушн-графика, 100 000+ Sand3D, Reels B-roll) → Проверка кадров и рендер MP4.
3. **Экосистема (3D-ноутбук + 4 карточки):** работает с большинством агентов (`Claude Code`, `Antigravity`, `Codex`, `DeepSeek Harness`, `QwenWork` и др.), форматы `16:9` и `9:16`, `Windows / macOS / Linux`, озвучка (`Edge TTS · 0 ₽`, `OpenRouter`, `AITunnel` и др.).
4. **Финал (Outro):** лаконичный финальный кадр `Montazhka` + `github.com/worldruschel/montazhka` без голосовой рекламы.
