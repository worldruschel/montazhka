Папка inbox/ — сюда кладите ваши исходные видеоклипы (.mp4, .mov, .mkv) для Reels, Shorts и YouTube.

Не прикрепляйте тяжёлые видеофайлы прямо в чат с ИИ-агентом (это тратит лишние токены) —
просто скопируйте файл сюда и напишите агенту, например:
  «Сделай Reels 9:16 из видео в inbox/my_clip.mp4: распознай речь, добавь субтитры и карточки.»

Файлы внутри inbox/ автоматически игнорируются Git и не попадут в репозиторий.
